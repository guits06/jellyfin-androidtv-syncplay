# Architecture & Optimization Decisions (`DECISIONS.md`)

Format: `- **[Area]** Decision — Reason | Rejected alternative`

- **[TV Environment]** Disabled system ad/telemetry packages on Chromecast HD (`com.google.android.adservices.api`, `com.google.android.ext.adservices.api`, `com.google.android.federatedcompute`, `com.google.android.ondevicepersonalization.services`, `com.android.tv.feedbackconsent`) via `pm disable-user --user 0` — Frees background CPU/RAM contention on 1.4 GB low-RAM target without affecting streaming apps or system stability | Leaving ad/personalization services running or disabling core GMS/Tailscale/Play Services.
- **[SyncPlay Architecture]** Model playback/SyncPlay event origins explicitly (`USER_LOCAL`, `REMOTE_SYNCPLAY`, `INTERNAL_PLAYER_TRANSITION`) instead of transient boolean `isHandlingRemoteCommand` — ExoPlayer transitions (`onIsPlayingChanged`, `STATE_BUFFERING`) execute asynchronously after `controller.play/pause/seek` returns, so synchronous booleans leak loopback events to the server | Increasing arbitrary coroutine delay timers around a boolean flag.
- **[SyncPlay Track/Burn-In Switching]** Handle audio/subtitle/burn-in stream rebuilds via an internal stream-reload transition (`INTERNAL_PLAYER_TRANSITION`) that preserves intended play/pause state and target SyncPlay position without reporting user `Stop`/`StartPlayback` — Changing subtitles to `ENCODE` (burn-in) or transcoding audio must appear transparent to other SyncPlay participants | Allowing `stop()` + `play()` to send `Stop` and `SetNewQueue` requests or force `PLAYING` when paused.
- **[UI Migration Strategy]** Replace individual Leanback Fragments (`HomeFragment`, `BrowseGridFragment`, `FullDetailsFragment`, `SearchFragment`) incrementally inside `DestinationFragmentView` using pure Jetpack Compose (`androidx.tv:tv-material:1.1.0`) — Preserves 100% of existing `NavigationRepository` destinations, arguments, and deep-links without risky single-shot rewrites | Keeping Leanback `RowsSupportFragment` wrappers (`AndroidFragment`) or rewriting all fragments into a monolithic graph at once.
- **[Image & Blur Pipeline]** Enforce global Coil `allowRgb565(true)`, 12% RAM / 96 MiB disk cache caps, exact pixel-bounded `Size`, and replace `Modifier.blur(10.dp)` in `AppBackground` with `drawWithCache` gradient scrims — Cuts bitmap memory by ~50% on 1080p TVs and eliminates heavy `RenderEffect` overdraw frame drops on Chromecast HD | Unbounded `ARGB_8888` image decoding and real-time GPU Gaussian blur.
- **[Hero Billboard Focus]** Debounce D-pad hero backdrop updates by `350ms` and animate card focus solely via GPU `graphicsLayer` springs (`CinemaMotion.FocusSpring`) — Prevents image decode/recomposition churn while rapid-scrolling rows on modest TV CPUs | Immediate per-focus backdrop swaps or layout-size animations.
